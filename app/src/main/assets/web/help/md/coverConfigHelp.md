# 封面设置帮助

封面设置用于控制书籍封面的加载、显示和默认封面来源。

---

## 通用设置

| 设置项 | 说明 |
|--------|------|
| 仅 WiFi 加载封面 | 开启后，移动网络下不加载网络封面，节省流量 |
| 高质量封面加载 | 开启后加载更清晰的封面图片，消耗更多流量和内存 |
| 封面阴影 | 为透明 PNG 封面提供统一底色，避免透明区域显示异常 |
| 封面规则 | 配置书源的封面搜索规则，用于自动获取网络封面 |
| HTML 封面 | 开启后，无封面的书籍可用 HTML 模板自动生成封面 |
| 封面图集 | 管理分组封面图集，可作为默认封面来源 |
| 使用默认封面 | 开启后，所有书籍强制显示默认封面，不加载网络封面 |

---

## 日间 / 夜间设置

日间和夜间主题的封面设置相互独立，切换主题时自动应用对应配置。

### 选用图集

从已创建的封面图集中选择一个分组，作为该主题下的默认封面来源。选择「无」则不使用图集。

### 封面模式

控制图集封面如何分配给书籍：

| 模式 | 说明 |
|------|------|
| **随机** | 每本书根据书名等信息随机分配图集中的图片，分配结果固定不变 |
| **顺序** | 每本书按首次加载顺序依次分配图集中的图片，循环使用（第 N 本书 → 图集第 (N mod 总数) 张） |
| **混合** | 已有网络封面的书籍使用网络封面，没有网络封面的书籍随机使用图集中的图片 |

> **顺序模式说明**：书籍的封面分配顺序取决于首次加载时机，与书架排列顺序无关。同一本书的封面在清除数据前保持不变。

### 默认封面

设置该主题下的默认封面图片。当书籍没有网络封面、也未启用图集时，使用此封面。

### 显示书名 / 显示作者

当书籍无封面时，在默认封面上绘制书名和作者文字。关闭「显示书名」后，「显示作者」自动禁用。

---

## 封面图集管理

在「封面图集」页面可以：

- **创建分组**：新建图集分组并添加图片
- **导入 ZIP**：从 ZIP 压缩包批量导入图片到新分组
- **设为默认**：将分组标记为数据库默认分组（未在设置中选用图集时使用）
- **重新随机**：重置随机种子和顺序分配，重新分配所有书籍的图集封面
- **导出 ZIP**：将分组图片导出为 ZIP 文件

### 图集封面优先级

1. 偏好设置中选用的图集分组
2. 数据库默认分组
3. 默认封面图片
