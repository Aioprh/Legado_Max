按书源脚本权限管理 —— 补全方案
现状：入口链路、Compose 界面骨架、四语言文案已完成，但权限无存储、无交互控件、无任何执行。以下按四个阶段补全，每阶段可独立编译验证。

阶段 1：数据层（存储 + 按源读写）
新建 app/src/main/java/io/legado/app/help/config/SourcePermission.kt：
data class SourcePermission：14 项权限（cookieRead/Write/Delete、bookRead/Modify/Delete、javaLang/javaIo/javaNet、androidContent/androidNet/androidSystem、toastEnabled、toastDurationMode(0跟随/1短/2长/3自定义)、toastDurationCustomMs），默认全部允许（保证现有书源零影响）。
object SourcePermissionManager：内存缓存（ConcurrentHashMap）+ 读写；存储复用 SourceConfig 的 SharedPreferences（SourceConfig.kt:10），key 为 perm_${sourceKey}，值 JSON。按 sourceKey 存，将来扩展订阅源零成本。
源删除时清理：SourceHelp.kt:99 已调 SourceConfig.removeSource(key)，在该方法内一并清除 perm_ 前缀 key。
阶段 2：UI 改造（两个入口）
权限页内选源：PermissionManageActivity 改为双屏：
新增书源列表屏（Compose LazyColumn：名称+地址+启用状态，带搜索框，数据来自 appDb.bookSourceDao()）；
点某源进入单源权限编辑页 = 改造现有 PermissionManageScreen：接收 sourceKey，新增 PermissionManageViewModel 加载/保存 SourcePermission（替换 PermissionSection.kt:37 注释所说的静态占位数据）。
每行加 Switch：复用 AppSettingSwitchItem 的样式风格（ui/widget/components/settings/AppSettingItems.kt:17），与现有图标行合并（图标+标题+描述+右侧开关，整行可点）。
Toast 时长行：点击弹对话框，单选「跟随脚本/强制短(2s)/强制长(3.5s)/自定义毫秒(数字输入)」。
Book 三项：可配置可保存，描述文案加「（暂未生效）」提示（本轮只存储不执行）。
书源管理菜单入口：res/menu/book_source_item.xml 加「权限管理」项，在 BookSourceActivity 的条目菜单点击处理中跳转 PermissionManageActivity 并传 sourceKey 直达编辑页。
新增字符串（搜索提示、时长选项、暂未生效提示）补齐 4 个 locale；顺手修复 values/strings.xml 末尾缺换行。
阶段 3：执行层 —— Cookie / Toast / 系统信息（均在 app 模块）
按源查权限的钥匙：AnalyzeRule/AnalyzeUrl/BaseSource 均持有 source，经 getSource()?.getKey() 查 SourcePermissionManager。

Cookie 读/写/删：新建代理类 PermissionCookieStore(perm) : CookieManagerInterface by CookieStore，被禁操作抛出带书源标签的明确异常（调试可见）。注入/拦截点：
3 个绑定点换成代理：AnalyzeRule.kt:1052、AnalyzeUrl.kt:369、BaseSource.kt:347；
JsExtensions.getCookie（JsExtensions.kt:413/418）加读权限检查；
隐蔽旁路：java.ajax 隐式附带/回写 cookie（AnalyzeUrl.kt:739 setCookie、响应自动保存）——被禁时静默跳过（不打断请求）；cache 绑定可读写 {domain}_cookie 内存项——新建 PermissionCacheManager 薄代理（手写委托 CacheManager 常用方法约 15 个），对 _cookie 结尾的 key 套用 cookie 权限，其余放行。
Toast：JsExtensions.toast/longToast（:1094/:1114）——toastEnabled 关闭时静默不弹；时长按 mode 覆盖传给 ToastUtils.toastOnUi 的 duration（自绘 View 的 Toast 支持自定义毫秒）。
系统信息：JsExtensions.androidId()（:1199）受 androidSystem 开关控制。
阶段 4：执行层 —— Java/Android 类访问（rhino 模块，仅危险类清单）
语义：编译期硬编码黑名单（Runtime/ClassLoader 等，RhinoClassShutter.kt:48-120）保持不变作为底线；每个 API 开关额外管控一份「可配置危险类清单」，关闭时该清单对该源脚本生效。

app 侧定义 ScriptClassPermissions：6 个开关各自的危险类清单（如 java.lang→System/Thread/ThreadGroup；java.io→各 Reader/Writer/Stream；java.net→URL/HttpURLConnection/Socket/ServerSocket；android.content→ContentResolver/ContentValues；android.net→ConnectivityManager/WifiManager/Uri；系统信息→Build/Settings/SystemProperties/StatFs）。
rhino 模块传递机制（避免 ThreadLocal 在协程切线程后失效）：
ScriptBindings 增加 var securityPolicy 属性；app 侧 3 个 evalJS 绑定点按源设置；
RhinoScriptEngine.getRuntimeScope(bindings) 时把 policy 拷贝到 RhinoContext（新增 var extraBlockedClasses）；
RhinoClassShutter.visibleToScripts(name)（:186）在硬编码检查外追加 (Context.getCurrentContext() as? RhinoContext)?.extraBlockedClasses 检查（注意让 ClassNameMatcher 的 LruCache 对动态部分失效或单独缓存）。
不在范围内（保持现状）：JsExtensions 自带的 readFile/deleteFile/getFile 等文件 API；这些不属于本次 14 项权限模型。
